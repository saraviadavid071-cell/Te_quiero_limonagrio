Objetivo Principal

Digitalizar y agilizar el registro de productos, clientes y ventas de una ferretería/comercio mediante una interfaz web rápida y fácil de usar.

Tecnologías Utilizadas

HTML5 para la estructura, CSS (Tailwind) para el diseño limpio y adaptable, y JavaScript básico para las tablas y formularios interactivos.
